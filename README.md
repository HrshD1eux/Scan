# Scan
An instant, ruthless, open-source Android QR and Barcode scanner.

## Philosophy
**Open instantly. Scan anything. Understand what it is. Give the user the correct action immediately.**

- **No Onboarding**
- **No Ads**
- **No Telemetry**
- **No Clutter**

Built with modern Android standards: Jetpack Compose, CameraX, ML Kit, and Room.
